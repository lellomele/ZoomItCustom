# ZoomIt Custom: istruzioni di progetto

## Commit e pubblicazioni
Per questo progetto preparare e verificare le modifiche in locale. Attendere una richiesta esplicita dell'utente prima di creare un commit, inviare modifiche a GitHub o pubblicare una release. Le autorizzazioni a pubblicare date prima del 4 ottobre 2026 non valgono per le versioni successive alla 1.1.1.

## Versioni
Mostrare i numeri di versione con tre componenti (per esempio 1.1.2) nel titolo, in About e nelle stringhe delle proprietà dell'eseguibile. Il campo numerico interno richiesto dal formato Windows può mantenere la quarta componente zero.
